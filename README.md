# End-to-End Retail Data Engineering & Business Intelligence Pipeline

An enterprise-grade data architecture lifecycle tracking retail transactions across regional Indian markets. This project showcases an end-to-end analytics workflow: programmatically generating data, cleaning anomalies, modeling financial schemas, and delivering interactive executive dashboard interfaces.

---

## 🛠️ Unified Tech Architecture Stack
- **Data Engineering & Ingestion:** Python 3 (Pandas, Random) via Jupyter Notebook
- **Data Warehousing & Structuring:** Microsoft Excel (Delimited parsing, Schema alignment)
- **Business Intelligence & Analytics:** Microsoft Power BI (DAX modeling, Star schema visualization)

---

## ⚙️ Core Pipeline Phases & Contributions

### 🔹 Phase 1: Data Engineering & Pipeline Automation (Python)
*Developed via architectural guidance from Gemini AI*
- **Simulated Ingestion:** Programmed a custom generator to simulate a comprehensive database tracking 600 retail orders across major Indian metropolitan areas.
- **Data Cleansing:** Implemented data-healing logic (`.fillna(0)`) to automatically scan transaction records, catch structural null anomalies, and normalize base attributes.
- **Feature Engineering:** Programmed math logic directly into the data matrix to calculate row-level financial totals (`Total_Revenue`) dynamically prior to export.

### 🔹 Phase 2: Database Storage & Validation (Excel)
- **Delimited Data Parsing:** Transformed and segmented raw CSV text configurations into structured analytical columns using Excel's Text-to-Columns delimiter wizard.

### 🔹 Phase 3: Interactive Visual Intelligence (Power BI)
*Developed via architectural guidance from Claude AI*
- **DAX Formula Engineering:** Designed and compiled custom performance metrics in Power BI using DAX formulas to accurately summarize total revenues, distinct transaction tallies, and gross units sold.
- **Executive Visual Dashboards:** Architected interactive visualization reports mapping high-level category summaries, geographic breakdowns, and trend frameworks.

---


## 📈 Executive Business Insights Discovered
1. **Dominant Regional Market:** Processing verified that **Delhi** represents the highest-converting geographic territory, outperforming other regional commercial clusters.
2. **Category Performance:** High-level grouping patterns pinpointed consumer spending distributions clearly across merchandise divisions, providing immediate directions for inventory planning.
